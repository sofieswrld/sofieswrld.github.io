## 문단과 인라인 문법

문단은 빈 줄로 구분합니다. 블로그에서는 긴 문장을 너무 빽빽하게 두기보다, 적당한 줄 간격으로 읽기 쉽게 남기는 것이 중요합니다.

두 번째 문단입니다. 문장 안에는 **굵은 글씨**, _기울임_, ***굵고 기울임***, ~~취소선~~, `인라인 코드`를 섞어 쓸 수 있습니다.

링크는 [Astro 공식 사이트](https://astro.build)처럼 작성합니다. 같은 글 안의 특정 섹션으로 이동하려면 [각주 섹션](#각주)처럼 내부 앵커를 걸 수 있습니다.

자동 링크도 확인합니다: <https://astro.build>

줄바꿈을 강제로 넣고 싶다면 문장 끝에 공백 두 칸을 넣거나 HTML `<br>`을 사용할 수 있습니다.<br>

## 목록

순서 없는 목록입니다.

- 좋아하는 문장을 모으기
- 나중에 다시 읽을 수 있게 남기기
- 너무 완성하려고 애쓰지 않기

순서 있는 목록입니다.

1. 생각을 적는다.
2. 잠깐 둔다.
3. 다시 읽고 다듬는다.

중첩 목록입니다.

- 글
  - 긴 호흡의 생각
    - 에세이
    - 회고
  - 에세이와 회고
    - 발행 전 메모
    - 다시 읽을 문장
  - 정리된 노트
    - 참고 링크
    - 추가 질문
- 조각글
  - 짧은 문장
    - 오늘의 문장
    - 다시 보고 싶은 문장
  - 이미지가 있는 순간
    - 한 장
    - 여러 장
  - 나중에 글이 될 씨앗
    - 제목 후보
    - 첫 문단

## 코드

인라인 코드는 `const note = "조각글"`처럼 보입니다.

TypeScript 코드 블록입니다.

```ts
type Post = {
  title: string;
  draft: boolean;
  tags: string[];
};

const publish = (post: Post) => {
  if (post.draft) return false;
  return post.tags.includes("sample");
};
```

HTML 코드 블록입니다.

```html
<article class="prose">
  <h1>마크다운 스타일 가이드</h1>
  <p>본문은 천천히 읽히는 속도로 남깁니다.</p>
</article>
```

Bash 코드 블록입니다.

```bash
npm run check
npm run build
```

일반 텍스트 코드 블록입니다.

```txt
소피의세계
├─ 글
└─ 조각글
```

## HTML 요소

마크다운 안에서는 필요한 경우 안전한 HTML을 섞어 쓸 수 있습니다.

<abbr title="HyperText Markup Language">HTML</abbr> 약어 표시를 확인합니다.

H<sub>2</sub>O처럼 아래첨자와 X<sup>n</sup>처럼 위첨자를 쓸 수 있습니다.

키보드 입력은 <kbd>⌘</kbd> + <kbd>K</kbd>처럼 표시합니다.

중요한 단어는 <mark>형광펜처럼 표시</mark>할 수 있습니다.

작은 보조 문장은 <small>이렇게 작게 표시됩니다.</small>

<details>
  <summary>접었다 펼칠 수 있는 details 요소</summary>
  <p>긴 설명이나 부가 정보를 숨겨두고 싶을 때 사용할 수 있습니다.</p>
</details>

정의 목록처럼 보이는 HTML입니다.

<dl>
  <dt>글</dt>
  <dd>조금 더 오래 생각한 것을 남기는 곳.</dd>
  <dt>조각글</dt>
  <dd>완성되기 전의 문장과 장면을 남기는 곳.</dd>
</dl>
